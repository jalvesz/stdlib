stdlib_bitsets (module)#

Implements zero based bitsets of size up to huge(0_int32). The current code uses 64 bit integers to store the bits and uses all 64 bits. The code assumes two’s complement integers, and treats negative integers as having the sign bit set. ([Specification](../page/specs/stdlib_bitsets.html)) Error flag indicating a failure on a WRITE statement
